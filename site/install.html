Five minutes to install.

One setup. All ten apps.

  1. Start from a jailbroken iPod touch 4 or iPhone 4 on iOS 4.3 and up. Legacy iOS Kit handles the downgrade and the jailbreak.
  2. Install AppSync for iOS 4, then TLSFix from cydia.skyglow.es and the certificate bundle at tlsroot.litten.ca. This gives iOS 4 modern HTTPS.
  3. Download an app and install it: ideviceinstaller install OpenRelay-1.2.ipa
  4. For Claude, enter your Anthropic API key in Settings → Claude. In Habits or Sets, choose Claude under AI Coach and enter the key in that app’s masked field. OpenRelay remains a separate provider with its own key. Keys are never bundled with downloads.
  5. For Meals, open Targets → Adaptive setup if you want weekly calorie and macro reviews. Log food and weigh-ins, and mark each finished diary day. Food logging and adaptive reviews work offline, without an account or API key.
  6. For Cards, put tools/cards from its repo on your Mac's PATH, write decks as Markdown files in ~/Cards, and run cards sync with the iPod plugged in.
